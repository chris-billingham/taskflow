# Labels & Filters

## Labels

Labels are tags you can apply to any task. Each label has a name and a color.

### Creating a Label

1. Open **Filters & Labels** from the sidebar
2. Click **+ Add label**
3. Enter a name and pick a color

### Applying Labels

Open any task and click the label area to pick from your labels. Tasks can have multiple labels.

### Filtering by Label

Click a label in the sidebar under **Filters & Labels** to see all tasks with that label, across all projects.

---

## Filters

Saved filters let you create custom views with complex conditions.

### Creating a Filter

1. Open **Filters & Labels** from the sidebar
2. Click **+ Add filter**
3. Name your filter
4. Add conditions:
   - **Project** is / is not
   - **Priority** is / is not
   - **Label** includes / excludes
   - **Due date** is / before / after / overdue / today / this week
   - **Assignee** is / is not
   - **Completed** is true / false
5. Choose **Match all** (AND) or **Match any** (OR)
6. Click **Save**

### Using a Filter

Click the filter in the sidebar to open it. The filter runs in real-time — add tasks anywhere and they appear in the filter view if they match.

### Editing a Filter

Click the `⋯` menu next to a filter name → **Edit**.
