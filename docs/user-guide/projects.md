# Projects

## Creating a Project

1. Click **+ Add project** at the bottom of the sidebar
2. Enter a name, choose a color (and optionally an icon)
3. Click **Create**

## Views

Switch views using the toolbar at the top of a project:

| View | Description |
|------|-------------|
| List | Default view — flat or grouped task list |
| Board | Kanban board — one column per section |
| Calendar | Month calendar showing tasks by due date |

## Sections

Sections divide a project into groups (e.g. "To Do", "In Progress", "Done" for a board).

- Click **+ Add section** at the top right of a project
- Drag sections to reorder them
- In Board view, each section becomes a column
- Tasks can be dragged between sections

## Archiving a Project

Open the project's `⋯` menu → **Archive**. Archived projects are hidden from the sidebar but their tasks remain searchable.

## Deleting a Project

Open the project's `⋯` menu → **Delete**. This permanently deletes the project and all its tasks.

## Sharing Projects (Workspaces)

Taskflow uses Workspaces for team collaboration. All members of a workspace can see shared projects. To invite someone:

1. Open **Workspace Settings** from the sidebar bottom menu
2. Click **Members** → **Invite member**
3. Enter their email address

See [collaboration.md](collaboration.md) for more on team features.
