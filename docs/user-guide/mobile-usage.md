# Mobile Usage

Taskflow is a responsive web app that works on phones and tablets.

## Layout

On mobile (< 768px):
- The sidebar is hidden by default — tap the **☰** menu button to open it
- Task lists fill the full screen
- The task detail panel opens as a bottom sheet

## Touch Interactions

| Gesture | Action |
|---------|--------|
| Tap | Open task / activate button |
| Long press | Select task for bulk actions |
| Swipe left | Quick-delete a task |
| Swipe right | Quick-complete a task |
| Pull to refresh | Refresh current view |

## Adding Tasks

Tap the **+** button (bottom right) to add a task. Quick Add with natural language parsing works the same as desktop.

## Limitations on Mobile

- Drag-and-drop reordering is not supported on touch devices — use the **Sort** menu instead
- The Board (Kanban) view scrolls horizontally on narrow screens
- Keyboard shortcuts are not available without a hardware keyboard

## Browser Compatibility

Taskflow works in all modern mobile browsers. For the best experience, use Chrome or Safari on iOS/Android.

## Progressive Web App (PWA)

On supported browsers, you can install Taskflow as a PWA:

**iOS Safari**: tap Share → Add to Home Screen  
**Android Chrome**: tap the browser menu → Add to Home Screen / Install app

Installed PWAs run in a standalone window and support browser push notifications.
