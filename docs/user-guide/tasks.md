# Tasks

## Creating a Task

**Methods:**
- Press `Q` to open Quick Add from anywhere
- Click **+ Add task** at the bottom of a list
- Click **+ Add task** inside a project

**Task fields:**

| Field | Description |
|-------|-------------|
| Content | The task name (required, max 500 chars) |
| Description | Rich text notes (markdown supported) |
| Due date | Date the task is due |
| Due time | Specific time on the due date |
| Deadline | Hard deadline (shown separately from due date) |
| Duration | Estimated time in minutes |
| Priority | 1 (urgent, red) → 4 (none) |
| Labels | One or more labels |
| Assignee | Team member (in shared workspaces) |
| Project | Which project it belongs to |
| Section | Which section within the project |
| Parent | Makes this a sub-task of another task |

## Completing a Task

Click the circle to the left of a task. Recurring tasks will reschedule automatically.

To uncomplete, click the filled circle again or open the task detail.

## Editing a Task

Click the task name to open the task detail panel. All fields are editable inline.

## Sub-tasks

Open a task detail panel and click **+ Add sub-task**. Sub-tasks appear nested below the parent.

## Recurring Tasks

In task detail, check **Recurring** and enter a recurrence rule:
- `every day`
- `every weekday`
- `every week`
- `every month`
- `every year`
- Standard iCal `RRULE` strings for advanced patterns

When a recurring task is completed, the next occurrence is created automatically.

## Bulk Actions

Select multiple tasks using the checkbox that appears on hover, then use the toolbar that appears:
- **Complete** — mark all selected as done
- **Delete** — delete all selected
- **Move** — move to another project/section
- **Priority** — set priority for all selected

## Reordering

Drag tasks by the drag handle (⠿) that appears on hover. Drag between sections to move.
