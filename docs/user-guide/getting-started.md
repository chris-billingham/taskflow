# Getting Started with Taskflow

## Creating Your Account

1. Open Taskflow in your browser (default: http://localhost:31779)
2. Click **Register** and enter your name, email, and a password (8+ characters)
3. You'll be taken directly to your **Today** view

## The Interface

```
┌─────────────────────────────────────────────────────┐
│  Sidebar          │  Main content area               │
│                   │                                  │
│  Today            │  Today                           │
│  Upcoming         │  ─────────────────────────────  │
│  Filters & Labels │  ○  Buy groceries     Today      │
│                   │  ○  Call dentist      Tomorrow   │
│  My Projects ▸    │                                  │
│  ● Work           │  + Add task                      │
│  ● Personal       │                                  │
└─────────────────────────────────────────────────────┘
```

- **Today** — tasks due today and any overdue tasks
- **Upcoming** — tasks due in the next 7 days
- **Filters & Labels** — manage your labels and saved filters
- **Projects** — your projects listed in the sidebar

## Your First Task

Click **+ Add task** at the bottom of any list, or press `Q` anywhere to open Quick Add.

Type a task name and press `Enter`. To set a due date and priority while typing:

```
Buy milk tomorrow p1
Call dentist next Monday @work
Review PR due 2025-05-10
```

Recognised keywords:
- **Date**: `today`, `tomorrow`, `next Monday`, `May 10`, `2025-05-10`
- **Priority**: `p1` (urgent), `p2` (high), `p3` (medium), `p4` / no tag (none)
- **Project**: `#ProjectName`

## Your First Project

1. Click **+ Add project** at the bottom of the sidebar
2. Enter a name and pick a color
3. Click **Create**

Your project appears in the sidebar. Click it to open it.
